## Projects

### QuickQR
#### Astro, React, TypeScript, Supabase
A QR code generator that creates static and dynamic QR codes with full customization and scan statistics tracking.  

### Janken – A One-Handed Journey
#### C++, OpenGL, X11, OpenAL
A role-playing combat game featuring dynamic sprite rendering, modular gameplay logic, and smooth visuals.  

### TCG Pack Opener
#### React, Supabase, SQL, PokeAPI 
A web app that simulates Pokémon card packs using a third-party API with user authentication and data saving.  

### typr.
#### HTML, CSS, JavaScript
A minimal typing test featuring real-time accuracy tracking, customizable word amounts, and simulated keyboard sounds.
